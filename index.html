GitHub 下载加速的常见场景

1. GitHub Releases 文件加速

Releases 页面的 .zip、.tar.gz、.exe、.dmg 等安装包体积大，国内直连经常中断或只有几十 KB/s。把 Releases 链接粘贴到上方输入框，选择延迟最低的节点，即可生成加速下载地址，支持断点续传场景下的稳定拉取。

2. GitHub Raw 文件加速

raw.githubusercontent.com 常用于加载脚本、配置文件和前端资源。这类单文件请求对延迟敏感，通过加速节点中转可明显缩短首字节时间，适合在 CI 脚本、油猴脚本、Dockerfile 中替换原始 raw 链接。

3. GitHub 源码归档加速

github.com/owner/repo/archive/refs/heads/main.zip 这类源码归档链接，体积从几 MB 到几百 MB 不等。加速节点支持 archive 链接直连下载，避免 git clone 卡在 resolving deltas 阶段。

4. Gist 与 Tags 页面加速

gist.github.com 的代码片段、以及仓库 tags 页面的归档链接，同样可以通过本工具生成加速地址，方便快速获取指定版本的源码。

常见问题

GitHub 下载慢怎么加速？

点击页面上的「一键测速」按钮，工具会自动测试各节点的延迟。将 GitHub 原始链接粘贴到输入框，即可实时生成加速链接，点击「下载」或「复制」使用。

支持哪些 GitHub 链接？

支持 Releases 文件与源码、archive 源码归档、blob、raw 单文件、gist 以及 tags 页面链接。带不带 https:// 协议头都可以识别。

加速是免费的吗？需要注册吗？

完全免费，无需注册登录。工具通过边缘节点中转请求，不存储你的文件内容。

为什么有时加速链接打不开？

公共加速节点可能因流量过大临时不可用。建议点击「一键测速」切换到其他节点，或稍后重试。留言板也欢迎反馈失效节点。
